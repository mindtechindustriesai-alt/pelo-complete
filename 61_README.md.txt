# PELO Community Safety Network

## Quick Panic System with GDV, Child Abuse, Attack, and Robbery Buttons

### Features
- 🚨 **One-tap panic buttons** for specific emergencies
- 💜 **GDV button** with silent callback option
- 👶 **Child Abuse button** direct to Childline SA
- 👊 **Attack button** auto-calls SAPS
- 💰 **Robbery button** alerts security and next-of-kin
- 📍 **Quantum accuracy location** (GPS + WiFi + cell)
- 🎥 **Video evidence upload** with chunked resumable upload
- 💬 **AI chat** powered by DeepSeek
- 🍳 **Budget recipes** for needy communities
- ⚛️ **Quantum verification badge** CHSH S=2.76

### Pricing
- **Standard:** R29/month
- **Needy Communities:** R19/month (requires approval)

### Deployment
1. Backend: Render.com (Python FastAPI)
2. Frontend: Netlify (HTML/CSS/JS)
3. Database: Firebase Firestore
4. Storage: Firebase Storage
